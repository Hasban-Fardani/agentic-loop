# Complexity

Gunakan `al complexity check`. Pengukuran memakai adapter Lizard bila tersedia;
threshold adalah policy task/repo, bukan angka hardcoded agent.

Exception wajib punya:

- fungsi/path;
- measured value;
- threshold;
- alasan;
- owner;
- expiry.

Missing required tool = UNKNOWN. Optional tool unavailable = explicit no-op.

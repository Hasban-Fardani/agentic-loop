# AEP Project Templates

Template ini opt-in melalui `al init --aep`. Root `AGENTS.md` menunjuk ke detail
workflow agar context awal agent tetap kecil.

Mulai dari `GOALS.md`, validasi readiness, pilih satu Plan aktif, lalu buat
Tasklist. Jangan menjalankan task sebelum dependency dan evidence contract valid.
